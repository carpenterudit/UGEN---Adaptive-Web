# UPGW Browser Extension Guide

## Overview

The UPGW Chrome Extension (Manifest V3) allows users to personalize and enhance readability on arbitrary webpages through a natural-language chat interface.

---

## Features
- **Adjust Font Size**: Scales text cleanly across body and article elements.
- **Enhance Readability**: Adjusts line spacing to 1.75 and sets optimal line length.
- **Theme Overrides**: Applies Dark, Warm Sepia, Calming Green, or Soft Blue themes.
- **Content Highlighting**: Subtle background accents for headings and key emphasis points.
- **Distraction Simplification**: Dims nonessential sidebars and ads.
- **Supplemental Reader Drawer**: Attaches an isolated drawer on the right edge.
- **Preview & Confirmation**: Shows proposed changes before applying.
- **One-Click Restore**: Restores the page to its exact original styling.

---

## Loading Unpacked Extension in Chrome / Edge

1. Open **Google Chrome** or **Microsoft Edge**.
2. Navigate to:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. Toggle on **Developer mode** in the upper-right corner.
4. Click **Load unpacked**.
5. Select the folder:
   ```
   universal-personalized-generative-web-v2/browser-extension
   ```
6. The extension is now active. Open any webpage and click the UPGW icon in the extensions bar.
